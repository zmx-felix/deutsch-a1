1. 词汇题：怎么背、怎么写才不丢分

1.1 一个德语名词必须记 3 样东西

卷子上的写法 das Brötchen- / die Suppe-n 不是随便写的：冠词 + 单词 + 复数词尾。只背中文意思，语法题（一格/四格）必然出错。

卷面写法中文复数为什么这样记
das Brot-e面包die Brote中性 + 复数加 -e
das Brötchen-小面包 / 面包卷die Brötchen“-chen”结尾永远是中性，复数不变
die Suppe-n汤die Suppen阴性 + 加 -n
der Salat-e沙拉 / 生菜die Salate阳性 + 加 -e
das Fleisch (sg.)肉无复数“sg.” = 只有单数，不可数
das Obst (sg.)水果无复数集合名词，永远单数
das Gemüse-蔬菜die Gemüse单复数同形
中国学生在这张卷子上最容易丢的 4 分
① das Obst / das Fleisch 不可数 → 说 viel Obst，不能说 Obsts；
② frühstücken 是动词“吃早餐”，das Frühstück 才是名词。翻译题里两个都考了，别写反；
③ das Brötchen 是“小面包/面包卷”，不是“面包”（面包是 das Brot）；
④ das Getränk（饮料）是可数的：die Getränke。

2. 语法题：判断“格”的三步法（这张卷子的核心）

2.1 万能三步法

① 找动词 → ② 问“这个动词管几格” → ③ 看名词的词性（der / das / die / 复数）→ ④ 套词尾表
词尾表（背这一张就够）阳性 der中性 das阴性 die复数 die
第一格 Nominativ
主语 / sein 后面		der / eindas / eindie / einedie / —
第四格 Akkusativ
动词的直接宾语		den / einendas / eindie / einedie / —
否定 keinkeinenkeinkeinekeine
一句话记住：只有阳性会变！der→den，ein→einen，kein→keinen。中性和阴性在第一格第四格长得一模一样。
所以做题时：先判断名词是不是阳性。不是阳性 → 直接抄第一格；是阳性 → 看动词是不是“吃/买/要/有”这类及物动词，是就加 -n。

2.2 第 4 单元 语法题（Akkusativ）答案

题目：Nominativ oder Akkusativ? Achten Sie auf das Verb. Ergänzen Sie ein in der richtigen Form.

#题目答案为什么
0Beispiel: Ich nehme noch ___ Kaffee.einennehmen 接第四格；der Kaffee 阳性
1Ich kaufe ___ Apfel.einenkaufen 接第四格；der Apfel 阳性
2Was möchten Sie? Ich möchte ___ Salat.einenmöchten 接第四格；der Salat 阳性
3Wo ist ___ Bäckerei? Ich brauche noch ___ Kuchen.die / einen① sein（ist）后面是第一格：die Bäckerei 阴性 → die；
② brauchen 接第四格：der Kuchen 阳性 → einen
4Ich koche ___ Suppe und wir essen ___ Brötchen dazu. Okay?eine / eindie Suppe 阴性（第四格还是 eine）；das Brötchen 中性（第四格还是 ein）
第 3 题是全卷最阴的一道：一句话里两个空，一个是第一格一个是第四格。
判断依据只有动词：ist（sein）→ 后面永远第一格；brauchen / kaufen / nehmen / essen / trinken / möchten → 后面第四格。
看到 Wo ist…? 就别想第四格了，问位置 = 问主语。

2.3 第 3 单元 语法题（ein / eine / kein / keine / der das die）答案

#题目答案为什么
1Was ist das? Das ist ___ Handy.eindas Handy 中性；sein 后面第一格 → ein
2Berlin ist ___ Land, Berlin ist ___ Stadt.kein / eine前半句否定：kein Land（das Land）；后半句肯定：eine Stadt（die Stadt 阴性）
3In Bremen ist ___ Hafen. ___ Hafen ist sehr groß.ein / Der第一次提到用不定冠词 ein；第二次提到必须用定冠词 Der（主语第一格，句首大写）
4Ist das ein Hotel? Nein, das ist ___ Hotel, das ist ___ Restaurant.kein / ein否定回答用 kein（das Hotel 中性 → kein）；肯定用 ein（das Restaurant 中性）
5Wie heißt der Fluss? Isar. Hier fahren leider ___ Schiffe.keinedie Schiffe 复数 → kein + e = keine
“第二次提到”规则 = 白送的分
德语里第一次出现某人/某物用 ein/eine，第二次再提就用 der/das/die。所以看到后半句是同一个名词，直接填定冠词，且要看它在句子里是不是主语（句首 = 第一格）。
另：Berlin 那句更地道的说法是 Berlin ist kein Land, sondern eine Stadt.（不是…而是…），sondern 后面直接跟名词。

4.1 四步听力法

第 1 步（播放前 10–20 秒）：只读题，不聊天。把题干里的疑问词圈出来 —— Was? Wo? Wann? Wie viel? Wohin? Wie lange? Welche(r)? 疑问词决定你听什么。
第 2 步：把三个选项的德语词在脑子里翻成中文（Teil 1 是三张图，先在图旁边写中文：Pommes 薯条 / Fisch 鱼 / Wurst 香肠）。
第 3 步：只听“和题目对应”的那一句，不需要每个词都懂。A1 听力每题的答案基本都在一句话里。
第 4 步：听完立刻涂，绝不回头纠结。一题 3 秒，别为了 1 分丢掉后面 3 题。

4.2 三个必考陷阱（听到这些词就要警觉）

陷阱录音里长这样正确做法

② 否定„Ich habe keine Zeit." / „Das ist nicht geöffnet." / „leider nicht"听到 nicht / kein / leider / nur / erst 就把答案反过来

5. 阅读理解（歌德 A1）：三种题型，三种解法

结构：3 部分、15 题、25 分钟。Teil 1 = 两封邮件/信（1–5 题，R/F）；Teil 2 = 5 个情景配广告（6–10 题，a/b 二选一）；Teil 3 = 5 个告示牌（11–15 题，R/F）。

阅读的唯一核心技巧：不要“读懂全文”，要“定位 + 比对”。
A1 阅读的正确答案几乎都是同义替换：题干说 A，原文用另一种说法说 A。干扰项则是“关键词对、但意思差一点”（时间差、方向差、数量差）。
所以做题顺序永远是：先读题干 → 圈关键词 → 回原文找那一句 → 逐字比对 → 再选。

Teil 1 的固定套路（第 1、3 题就是这么错的）
① 时间错位：letztes Wochenende ↔ kommender Sonntag；morgen ↔ gestern
② 数量夸大/缩小：nur zwei ↔ viele；alle ↔ einige
③ 正反颠倒：Urlaub ↔ arbeiten；draußen ↔ drinnen
④ 人物错位：问 Renate，原文说的是 Nora（A1 很喜欢换人）
做题时把题干里的时间词、数量词、人圈出来，回原文只比这几样。

Teil 3 的判断口诀

#错误写法正确写法原因
1du esst / er esstdu isst / er isstessen 换音 e→i，只 du/er
2ihr fährtihr fahrtihr 永远不变音
3ich wisse / er wisstich weiß / er weißwissen 单数是 weiß
4ich mochteich möchtemöchten 有 umlaut + t
5Ich kaufe ein Apfel.Ich kaufe einen Apfel.阳性 + 第四格 = einen
6Hier fahren kein Schiffe.Hier fahren keine Schiffe.复数用 keine
7Ein Hafen ist sehr groß.（第二次提到）Der Hafen ist sehr groß.第二次提到用定冠词
8Ich frühstücke das Frühstück.Ich frühstücke um 8 Uhr.frühstücken 本身就是“吃早餐”
9in dem Frühling / in Märzim Frühling / im März月份季节一律 im
10halb 5 = 5:30halb 5 = 4:30德语“半点”指下一个小时的前半小时
11周六下午去邮局samstags nur 8–12 Uhr时间边界题，下午关门
12Meine Schwester isst…（当 er 用）Meine Schwester kauft…Schwester = sie，不是 er
13Ich am Samstag gehe…Am Samstag gehe ich…动词必须第二位
14Steigen Sie ein! 写成 Einsteigen Sie!Steigen Sie ein!可分动词在祈使句要拆开
15Ich möchte am samstag ins restaurant gehen.Ich möchte am Samstag ins Restaurant gehen.德语名词全部大写
